Hey, thank you for checking out Spotify Plus! The extension version :O This is is still very much so in development! However, there is a preview version! Please check it out if you are a developer and want to build something cool! 

My dream has always been to bring something like spicetify to mobile. We are getting very close! You can build extensions and share them with everyone in the marketplace. This is very cool!

Make sure to check out the [docs!](https://lenerd46.github.io/spotifyplus-docs/docs/category/getting-started)
